# Power BI Dashboard Documentation

## Dashboard pages

### 1. Inventory Overview
A high-level view of inventory status and summary metrics.

### 2. Monthly Trends
A time-based view of transaction or inventory trends across the available period.

### 3. Product Analysis
A product-focused view for comparing items and their activity.

### 4. Stock Risk
A view designed to highlight products that may need replenishment. Check the report's specific reorder logic before comparing it with SQL's fixed threshold.

### 5. Sales & Revenue Analysis
A sales/revenue-oriented view built from the demonstration dataset.
